# Archivo (share card)

Static Archivo cuts for the promo share card (src/app/api/share-card), the
site's display face (.rd-display is Archivo 800). Satori reads neither
variable fonts nor WOFF2, so the static TTFs are committed here.

- Copied 2026-11-03 from the app repo's bundled set (promonight
  assets/fonts/archivo), itself from https://github.com/Omnibus-Type/Archivo
  `fonts/ttf/` on `master`, downloaded 2026-10-06. Unmodified.
- License: SIL Open Font License 1.1, text in `OFL.txt` beside these files.
- Weights: SemiBold 600, Bold 700, ExtraBold 800.
