# Promo explainers

One file per key. Frontmatter: key, kind (type|theme), title, faqs[{q,a}]. Body is the explainer prose.

Rules (see docs/per-promo-pages-v2-spec.md): general claims only, never about a specific game; second person; plain; no em dashes; 80 to 160 words; 2 to 4 FAQs. Lookup cascade on the promo page: themeKey, else type, else render nothing. Reviewed by Matt before merge.
