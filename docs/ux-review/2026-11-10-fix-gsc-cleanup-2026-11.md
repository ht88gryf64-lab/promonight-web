### Process findings

- **X1: the branch render is not HEAD alone.** `git status` in the worktree shows ` M src/lib/promo-page-copy.ts`, modified 10:55, which I did not make. The edit changes the prefix list in `stripRedundantPrefix` (drops the joined `city nickname` entry and keeps `teamName`, `nickname`, `city`, `season`). The dev server was serving 3ca5472 plus that edit. Only the over-budget package title fallback uses that function, and none of the reviewed pages takes that path: the Timberwolves title fits on the shorter `{name} | {nickname}` form. So no result here depends on the edit. Still, what was reviewed is not exactly what is committed.
- **X2: the `filter-chips.tsx` change was not exercised by any served page.** `/best-promos` and `/team-rankings` both mount `LeagueFilter` in controlled mode (`FilterChipsView`) and write the URL with `history.replaceState` in `best-promos-browser.tsx` and `team-rankings-list.tsx`. Those two call sites were tested and pass (see those sections). The URL-synced `FilterChips` (`router.replace`) is mounted by neither page, and the date-range chips are hidden on `/best-promos` while it is retrospective, so the `range` parameter was not exercised either.
- The dev server answered one `/cfb` request with **500** (`TypeError: __webpack_modules__[moduleId] is not a function` in the dev log). Three refetches returned 200. This is a dev-compile artifact consistent with the file edit in X1, not a page defect.

- Ticketmaster links on the branch are bare `www.ticketmaster.com` URLs, without the `ticketmaster.evyy.net` Impact wrapper. `NEXT_PUBLIC_TICKETMASTER_IMPACT_WRAP` is unset on the dev server. This is environment only, and it is the only main-content HTML difference on five of the seven pages.
